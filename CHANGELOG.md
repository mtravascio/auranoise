# Changelog

All notable changes to the AuraNoise project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]\n
### Added
- Initial project structure
- 14 built-in ambient sounds (rain, storm, wind, waves, stream, birds, summer-night, train, boat, city, coffee-shop, fireplace, pink-noise, white-noise)
- Custom sound support (OGG, MP3, WAV, AAC, FLAC, M4A, OPUS)
- Preset system for saving sound combinations
- Individual volume controls per sound
- Global volume multiplier
- Hide inactive sounds option
- Dark/Light theme support
- SVG icons for all built-in sounds
- Compact UI design (140px cards, 56px icons)
- Background audio preloading
- Lazy AudioPlayer initialization for performance

## [1.0.0] - 2024-03-30

### Added
- Initial release
- Cross-platform support (Android, Linux, Windows, Web)
- Material 3 design
- Settings persistence via SharedPreferences
- Audio playback using just_audio
- Desktop support via just_audio_media_kit
